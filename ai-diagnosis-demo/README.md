## 🎯 8 分钟三段演示流程

### 主流程（8 分钟·全场景）

```
[0:00-2:00] 诊前（患者端 · 2 分钟）
   ├─ [0:00] P-2 患者预诊（输入"咳嗽 3 天" + 档案 opt-in）
   ├─ [0:30] P-1 AI 追问（"有痰？颜色？""喘吗？"）
   └─ [1:30] P0 挂号确认（选内科张文华医生 14:30）

[2:00-6:30] 诊中（医生端 · 4.5 分钟 · 一页式不跳页）
   ├─ [2:00] P2 工作台（点"开始接诊" → 王秀英进诊间）
   ├─ [2:30] P3 接诊中 ⭐（左右分栏）
   │   ├─ 左侧：患者信息（预诊带入）+ 主诉/现病史（预诊带入 + 录音补充）
   │   ├─ 左侧：症状/体征勾选 + 处方按钮（弹窗）
   │   ├─ 右侧：AI 诊断（手动触发）→ Top 3 + 三按钮
   │   ├─ 右侧：推荐检查 5 项 + 开检查单按钮（弹窗，诊中分流）
   │   └─ 右侧：治疗方案
   ├─ [3:00] 点"触发 AI 诊断" → 1.8s 推理 → 显示 Top 3
   ├─ [3:30] 点"💊 开方" → 弹窗（过敏冲突实时警告）
   ├─ [4:00] 点"🩺 开检查单" → 弹窗（诊中分流演示）
   ├─ [4:30] 点"✅ 完成接诊" → 弹"AI 随访配置"弹窗 → 跳工作台
   └─ （诊中分流演示如需独立）点 P0.5 危急值页演示 4 通道强推

[6:30-8:00] 诊后（医生端 · 1.5 分钟）
   ├─ [6:30] P6 AI 随访配置（5 任务自动配置）
   ├─ [7:00] P7 随访工作台（看 1 危急值 + 1 报告超 24h）
   └─ [7:30] P0.5 危急值详情（4 通道强推+30min 已读演示）
```

## ⚠️ V2.0 异常场景（4 大新增）

| 段 | 场景 | 触发 | 表现 |
|---|---|---|---|
| 诊前 | 预诊模型宕机 | 推理失败 | 灰色占位 + "请到导诊台" |
| 诊前 | 预诊超时 | API > 5s | 加载动画 + 30s 后降级 |
| 诊中 | 语音 ASR 失败 | 网络错误 | 降级手动 + 录音保留 |
| 诊中 | AI 诊断宕机 | 推理失败 | 灰色占位 + 按经验 |
| **诊中·检查** | **检查单 24h 未回** | 阈值 | 状态变橙色 + 推送 |
| **诊中·检查** | **危急值** | LIS 异常 | 4 通道强推 + 30min 倒计时 |
| **诊中·检查** | **换医生** | 报告回流时原医生不在岗 | 推值班医生 + 接管按钮 |
| **诊中·检查** | **医生下班** | 报告出时医生已下班 | "待我处理"队列 7 天 |
| 诊后 | 随访不响应 | 推送 3 次 | 降级 + 客服 |

## 💡 提示

- 所有数据是 **mock**（不真实保存）
- 刷新页面会 **重置状态**
- **推荐用 Chrome** 打开（兼容性最好）
- 演示前 **关闭其他标签页**（避免加载慢）
- 部分页面用 mobile-first 设计（手机壳 UI），大屏演示时显示"一体机说明"侧栏
- 录音按钮：演示时点 1 次开启，等 3 秒再点 1 次关闭，会看到 AI 转写动画
- 危急值页：30 分钟倒计时是写死"剩余 28:42"，演示用，不实时
